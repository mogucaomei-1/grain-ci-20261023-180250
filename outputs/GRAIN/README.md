# GRAIN 1.1 — Sony RAW 胶片工作台

GRAIN 是一个面向 iPhone 的 SwiftUI RAW 调色 App。主流程围绕 Sony ARW 导入、胶片色彩模拟、原尺寸高质量导出和 GPS 隐私开关设计。当前测试包为 1.1 (57)。

## 打开方式

1. 用 Xcode 16 或更高版本打开 `GRAIN.xcodeproj`。
2. 在 `Signing & Capabilities` 中选择自己的开发团队。
3. 如需改 Bundle Identifier，替换 `studio.grain.rawfilm`。
4. 选择 iPhone 17 Pro 模拟器或真机运行。

当前制作环境没有安装完整 Xcode/iOS SDK，因此已完成项目结构校验、Swift 语法检查和 Core Image 核心代码的 macOS SDK 类型检查，但不能在这里生成 `.app` 或运行 iPhone 模拟器。

## 已实现

- 通过 `CIRAWFilter` 解码 Sony ARW，并以原尺寸校验阻止内嵌 JPEG 被误当 RAW；照片图库优先，文件导入使用原生 `UIDocumentPicker` 的 `asCopy` 模式。
- 照片图库导入会请求读取权限，并通过 `PHAssetResource` 从 iCloud 获取原始资源；并发选择会取消并丢弃过期结果，避免打开成另一张照片。
- 主页直接显示照片图库网格；顶栏的相册与文件导入拆分为两个独立入口。
- 预览固定渲染约 1800 px 长边，避免每次拖动参数都解码整张高像素 RAW。
- 导出时重新从 RAW 读取全尺寸图像，默认保持原始像素，不提供隐式缩小。
- 默认 HEIC，质量 100%；可切换 JPEG，质量 100%；HEIC 不可用时自动回退 JPEG。
- 输出 Display P3，保留相机、镜头、拍摄时间等 EXIF/TIFF 字段。
- “保留地址信息”开关控制 GPS 字典及 IPTC 位置字段，关闭后不会写入导出文件。
- 28 套中文命名的彩色胶片配方，并保留独立“原图”选项，覆盖彩色负片、反转片、电影胶片及 Dazz 高频滤镜灵感。
- 可调曝光、对比、高光、阴影、白色、黑色、色温、色调、自然饱和度、饱和度、清晰度、锐化、褪色、颗粒、暗角和配方强度。
- 单页实时预览、长按查看原片、返回主页、相机与原始像素信息、导出结果分享。
- “推荐”按钮在本地分析亮度、饱和度、冷暖、高光与阴影，自动选择胶片、曝光和色温，不上传照片到第三方服务。
- “复制 / 粘贴”可将完整胶片与参数预设带到下一张照片。
- 支持自由与固定比例裁剪、90° 旋转、水平/垂直翻转及非破坏性重新编辑。
- 支持多个文字图层、三种字体、任意颜色、字号调整、九宫格吸附拖动和 Emoji，并写入最终导出文件。拖动采用合成层位移，过程中持续轻触、进入吸附点时增强反馈。
- 胶片栏提供常驻强度滑杆，0% 回到无滤镜、100% 使用完整配方；新增经典负片、怀旧负片、REALA ACE、ETERNA、ColorPlus 200、Ultramax 400、C200、E100 和 Vision3 500T。
- Dazz 灵感滤镜按高优先级排列，包含 FXN R、CCD R、D Classic、GRD R、D FunS、Classic U；再次点击已选滤镜可切回原图。
- 内置 AVFoundation 后置相机，支持 0.5/1/2/4/8 倍率、24MP/48MP、实况照片、闪光灯、画面比例、3 秒/10 秒计时器及 HEIF/PNG/RAW 输出。
- 相机支持点按 AF/AE、长按锁定对焦曝光、双指缩放、曝光补偿、前后镜头切换和九宫格开关；主页直方图开关移入左上角 Logo 设置页。
- 相机支持实时胶片滤镜与强度预览、左侧右滑返回图库；0.5× 显式切换超广角镜头。编辑器采用照片优先的两页工具区，首次启动立即请求 Apple 连通性地址以触发网络权限。
- 照片编辑主画布采用铺满式显示，竖屏照片优先占用屏幕宽度；相机预览与底部工具栏分离，并采用更高分辨率实时滤镜渲染。
- 编辑器取消橙色页签滑条，改用当前页图标与文字高亮；横屏照片按真实比例完整显示。相机实时滤镜、对焦反馈、0.5× 超广角和拍摄稳定性已针对 iPhone 17 Pro 优化。
- 画布比例直接读取已完成 EXIF 旋转的预览图尺寸，避免竖拍 RAW 被误判为横图。相机拍摄通过临时文件写入系统相册，并默认使用原图滤镜。
- 相机底部滤镜改为按需展开，默认保持原图并减少功能栏占用；主页相机和文件导入入口可在 Logo 设置页分别开关。
- 照片画布按已旋转预览图的真实比例完整显示；相机拍摄采用 ImageIO 限内存处理、PhotoKit 临时文件保存，并限制实时预览帧堆积以降低快门闪退风险。
- 相机默认关闭闪光灯，拍摄调用固定到主线程并使用系统默认 PhotoSettings；相册权限与相机权限在首次启动时一起请求。
- 视频预览和照片输出在相机会话初始化时一次挂载，按下快门时不再增删输出，避免拍摄过程中重建采集管线导致闪退或预览冻结。
- 自动选择设备支持的最高静态照片格式；24MP/48MP 切换会直接更新 PhotoOutput 的拍照尺寸，RAW 与实况照片共用同一稳定输出。
- 麦克风只在用户主动开启实况照片时加入会话；照片先写入临时资源再保存到照片图库，相机底部提供最近拍摄缩略图并可直接返回图库。
- 首次启动新增独立权限页，分别引导网络、相机、麦克风、照片图库权限；相机不再使用已废弃的 StillImageOutput。
- 相机倍率使用系统原生三摄虚拟设备，在同一个相机会话内自动完成 0.5× 超广角、1×/2× 主摄、4× 原生长焦与 8× 长焦裁切，避免切换倍率时重建输入导致崩溃。
- 支持自由涂抹马赛克，可调笔刷大小、撤销单笔和清空全部；效果会写入原尺寸导出文件。
- 点击照片进入全屏后会从原始文件重新解码全分辨率图像，缩放查看的是当前调色、裁剪和马赛克后的原尺寸细节。
- 胶片区域最右侧可进入排序编辑页，拖动调整胶片顺序后会持久化并立即同步到编辑页胶片栏。
- 胶片、相机实时滤镜与胶片排序页统一使用带机身、镜头环、取景窗和闪光灯的相机图标；Dazz 灵感滤镜、拍立得配方与便携机配方分别采用不同轮廓。
- 顶栏信息按钮可查看文件名、原尺寸、像素、文件大小、机型、镜头、拍摄时间与 GPS 坐标。
- 主屏幕图标和软件内标识均使用叠放照片与调色滑杆，明确表达图片编辑工具；主页图库支持长按进入多选、滑动连续选择、取消选择和删除照片。
- 长按多选照片后可进入拼图，最多选择 10 张并按选择顺序进行横向或纵向单列拼接；支持保存到照片图库以及通过系统分享面板发送到其他 App。
- 左侧边缘右滑可返回照片图库；相机图标可进入设置并开关参数滑块、文字吸附和返回手势的震动反馈。

## 关键文件

- `GRAIN/ImageProcessor.swift`：RAW 解码、预览、色彩管线、全尺寸导出和元数据策略。
- `GRAIN/Models.swift`：照片模型、28 套胶片配方与导出参数。
- `GRAIN/EditorViewModel.swift`：导入、后台预览、取消旧任务和导出状态。
- `GRAIN/Views.swift`：无滚动单页编辑器、实时胶片横栏和紧凑导出面板。
- `GRAIN/PhotosImporter.swift`：保留原始文件表示方式的照片图库导入器。

## Sony RAW 兼容性

Sony ARW 的实际解码能力由 iOS/macOS 自带的 Core Image RAW 管线决定，而不是 App 自建解码器。多数主流 Sony 机身已获支持，但非常新的机型、部分压缩 RAW 变体或新固件可能要求更新 iOS。工程会在无法解码时显示明确错误，不会把缩略图冒充全尺寸输出。

正式上架前建议加入一份目标机身清单做回归测试，例如 A7 IV、A7R V、A7C II、A1 II 和 FX3，并使用未压缩、无损压缩及有损压缩 ARW 各测一张。

## 定位与元数据说明

从“文件” App 导入时最容易完整保留 RAW 自身的 EXIF/GPS。通过系统照片选择器导入时，定位是否仍在源文件中取决于 iOS 返回的资产副本与用户授权；RAW+JPEG 资产也可能只返回 JPEG 副本。

关闭地址信息会移除 GPS 主字典，并清理 IPTC 中常见的位置字段；相机、镜头、快门、光圈、ISO 与拍摄时间仍可保留。

## 产出边界

这是可继续开发的 MVP 源码，不是已经签名上架的 App。需要完整 Xcode 环境完成最终编译、真机 RAW 样本测试、App Store 隐私清单和应用图标尺寸校验。
