# GRAIN 1.1 — Sony RAW 胶片工作台

GRAIN 是一个面向 iPhone 的 SwiftUI RAW 调色 App。主流程围绕 Sony ARW 导入、胶片色彩模拟、原尺寸高质量导出和 GPS 隐私开关设计。当前测试包为 1.1 (73)。

## 打开方式

1. 用 Xcode 16 或更高版本打开 `GRAIN.xcodeproj`。
2. 在 `Signing & Capabilities` 中选择自己的开发团队。
3. 如需改 Bundle Identifier，替换 `studio.grain.rawfilm`。
4. 选择 iPhone 17 Pro 模拟器或真机运行。

当前制作环境没有安装完整 Xcode/iOS SDK，因此已完成项目结构校验、Swift 语法检查和 Core Image 核心代码的 macOS SDK 类型检查，但不能在这里生成 `.app` 或运行 iPhone 模拟器。

## 已实现

- 通过 `CIRAWFilter` 解码 Sony ARW，并以原尺寸校验阻止内嵌 JPEG 被误当 RAW；照片图库优先，文件导入使用原生 `UIDocumentPicker` 的 `asCopy` 模式。
- 照片图库导入会请求读取权限，并通过 `PHAssetResource` 从 iCloud 获取原始资源；并发选择会取消并丢弃过期结果，避免打开成另一张照片。
- 主页直接显示照片图库网格；顶栏的相册与文件导入拆分为两个独立入口。
- 预览固定渲染约 1800 px 长边，避免每次拖动参数都解码整张高像素 RAW。
- 导出时重新从 RAW 读取全尺寸图像，默认保持原始像素，不提供隐式缩小。
- 默认 HEIC，质量 100%；可切换 JPEG，质量 100%；HEIC 不可用时自动回退 JPEG。
- 输出 Display P3，保留相机、镜头、拍摄时间等 EXIF/TIFF 字段。
- “保留地址信息”开关控制 GPS 字典及 IPTC 位置字段，关闭后不会写入导出文件。
- 28 套中文命名的彩色胶片配方，并保留独立“原图”选项，覆盖彩色负片、反转片、电影胶片及 Dazz 高频滤镜灵感。
- 可调曝光、对比、高光、阴影、白色、黑色、色温、色调、自然饱和度、饱和度、清晰度、锐化、褪色、颗粒、暗角和配方强度。
- 单页实时预览、长按查看原片、返回主页、相机与原始像素信息、导出结果分享。
- “推荐”按钮在本地分析亮度、饱和度、冷暖、高光与阴影，自动选择胶片、曝光和色温，不上传照片到第三方服务。
- “复制 / 粘贴”可将完整胶片与参数预设带到下一张照片。
- 支持自由与固定比例裁剪、90° 旋转、水平/垂直翻转及非破坏性重新编辑。
- 支持多个文字图层、三种字体、任意颜色、字号调整、九宫格吸附拖动和 Emoji，并写入最终导出文件。拖动采用合成层位移，过程中持续轻触、进入吸附点时增强反馈。
- 胶片栏提供常驻强度滑杆，0% 回到无滤镜、100% 使用完整配方；新增经典负片、怀旧负片、REALA ACE、ETERNA、ColorPlus 200、Ultramax 400、C200、E100 和 Vision3 500T。
- Dazz 灵感滤镜按高优先级排列，包含 FXN R、CCD R、D Classic、GRD R、D FunS、Classic U；再次点击已选滤镜可切回原图。
- 内置 AVFoundation 后置相机，支持 0.5/1/2/4/8 倍率、24MP/48MP、实况照片、闪光灯、画面比例、3 秒/10 秒计时器及 HEIF/PNG/RAW 输出。
- 相机支持点按 AF/AE、长按锁定对焦曝光、双指缩放、曝光补偿、前后镜头切换和九宫格开关；主页直方图开关移入左上角 Logo 设置页。
- 相机支持实时胶片滤镜与强度预览、左侧右滑返回图库；0.5× 显式切换超广角镜头。编辑器采用照片优先的两页工具区，首次启动立即请求 Apple 连通性地址以触发网络权限。
- 照片编辑主画布采用铺满式显示，竖屏照片优先占用屏幕宽度；相机预览与底部工具栏分离，并采用更高分辨率实时滤镜渲染。
- 编辑器取消橙色页签滑条，改用当前页图标与文字高亮；横屏照片按真实比例完整显示。相机实时滤镜、对焦反馈、0.5× 超广角和拍摄稳定性已针对 iPhone 17 Pro 优化。
- 画布比例直接读取已完成 EXIF 旋转的预览图尺寸，避免竖拍 RAW 被误判为横图。相机拍摄通过临时文件写入系统相册，并默认使用原图滤镜。
- 相机底部滤镜改为按需展开，默认保持原图并减少功能栏占用；主页相机和文件导入入口可在 Logo 设置页分别开关。
- 照片画布按已旋转预览图的真实比例完整显示；相机拍摄采用 ImageIO 限内存处理、PhotoKit 临时文件保存，并限制实时预览帧堆积以降低快门闪退风险。
- 相机默认关闭闪光灯，拍摄调用固定到主线程并使用系统默认 PhotoSettings；相册权限与相机权限在首次启动时一起请求。
- 视频预览和照片输出在相机会话初始化时一次挂载，按下快门时不再增删输出，避免拍摄过程中重建采集管线导致闪退或预览冻结。
- 自动选择设备支持的最高静态照片格式；24MP/48MP 切换会直接更新 PhotoOutput 的拍照尺寸，RAW 与实况照片共用同一稳定输出。
- 麦克风只在用户主动开启实况照片时加入会话；照片先写入临时资源再保存到照片图库，相机底部提供最近拍摄缩略图并可直接返回图库。
- 首次启动新增独立权限页，分别引导网络、相机、麦克风、照片图库权限；相机不再使用已废弃的 StillImageOutput。
- 相机倍率使用系统原生三摄虚拟设备，在同一个相机会话内自动完成 0.5× 超广角、1×/2× 主摄、4× 原生长焦与 8× 长焦裁切，避免切换倍率时重建输入导致崩溃。
- 支持自由涂抹马赛克，可调笔刷大小、撤销单笔和清空全部；效果会写入原尺寸导出文件。
- 点击照片进入全屏后会从原始文件重新解码全分辨率图像，缩放查看的是当前调色、裁剪和马赛克后的原尺寸细节。
- 胶片区域最右侧可进入排序编辑页，拖动调整胶片顺序后会持久化并立即同步到编辑页胶片栏。
- 胶片、相机实时滤镜与胶片排序页统一使用带机身、镜头环、取景窗和闪光灯的相机图标；Dazz 灵感滤镜、拍立得配方与便携机配方分别采用不同轮廓。
- 顶栏信息按钮可查看文件名、原尺寸、像素、文件大小、机型、镜头、拍摄时间与 GPS 坐标。
- 主屏幕图标和软件内标识均使用叠放照片与调色滑杆，明确表达图片编辑工具；主页图库支持长按进入多选、滑动连续选择、取消选择和删除照片。
- 主页顶部提供可关闭的拼图入口；拼图内可继续从照片图库添加照片，最多 10 张，并按选择顺序进行横向或纵向单列拼接。
- 拼图支持保存到照片图库以及通过系统分享面板发送到其他 App；主页多选数量不受 10 张限制，并可直接分享所选的原始照片。
- 左侧边缘右滑可返回照片图库；相机图标可进入设置并开关参数滑块、文字吸附和返回手势的震动反馈。
- 相机左下角缩略图在拍完照后可直接打开刚拍摄的那张照片进入编辑，而不是退回主页；编辑页顶栏新增删除按钮，图库来源的照片会一并从系统相册删除（需确认）。
- 权限启动页统一使用主题橙色：左侧图标始终为橙色，右侧按钮文字默认为白色，开启后变为橙色；麦克风一项明确标注为实况照片所需。
- 拼图入口只保留主页顶栏的拼图按钮；长按进入多选后的工具条只保留分享与删除，移除重复的拼图按钮和“最多 10 张”限制提示。
- 相机静态照片改用主摄物理设备（`builtInWideAngleCamera`），会话切到 `.inputPriority` 后再选最高分辨率格式并设置 `maxPhotoDimensions`：24MP/48MP 现在按主摄满分辨率采集、导出阶段降采样，ProRAW（48MP DNG）恢复可用。
- 修复拍摄实况照片闪退：ProRAW 与实况照片互斥，不再在会话建立时无条件开启 ProRAW；每次拍摄按格式切换，并在开启实况照片前关闭 ProRAW、关闭后再设 12MP 尺寸。
- RAW 分辨率按镜头约束：ProRAW 的 24/48MP 仅主摄 1× 请求，超广角、长焦、数码变焦统一按 12MP 采集；镜头切换后同步更新照片输出上限，避免沿用主摄 48MP。
- RAW 只接受 ProRAW 像素格式，不再回退 Bayer RAW，避免照片图库以 3302 拒绝不兼容的 DNG。
- RAW 采集按所选分辨率逐张设置 `maxPhotoDimensions` 并使用 `.quality` 优先级：48MP 输出 48MP ProRAW，24MP 尝试 24MP ProRAW（ProRAW 仅原生支持 12/48MP，不支持时系统会回落到可用档位，拍摄完成的提示会显示实际像素）。
- 相机导出交给 ImageIO 的 `CreateThumbnailWithTransform` 按 EXIF 方向生成正向像素，再按比例裁切、精确缩放到目标像素；修复竖拍照片上下颠倒，同时保持 24MP/48MP 输出像素准确。
- RAW 写入相册时使用正确的 DNG UTI（`com.adobe.raw-image`），并按“文件+元数据 → 仅文件 → 内存数据”顺序重试；修复选择 RAW 拍照时 PHPhotosError 3302。
- 照片输出常驻会话，不再每次快门移除/添加 `AVCapturePhotoOutput`；尺寸只在 12MP（实况照片）与满分辨率之间切换，两者都对 ProRAW 合法，避免尺寸校验异常导致的闪退。

- 非 RAW 拍摄（HEIF/JPEG/PNG）会把 `AVCapturePhoto` 的 EXIF/TIFF/GPS 写入重编码文件，图片信息页可显示机型、镜头、拍摄时间与位置；TIFF 也加入导入支持。
- 新增“位置信息”“机型与镜头参数”两个拍摄开关：关闭位置后不写入 GPS/相册位置，关闭机型后移除 TIFF Make/Model 与 EXIF 镜头字段；定位权限在首次开启位置开关（或进相机）时按需申请。
- 编辑页照片格式标签按实际文件扩展名显示 RAW / HEIF / PNG / JPEG / TIFF，不再一律显示 RAW；主页图库缩略图左上角也会显示对应格式徽标。
- 编辑页主画布支持左右滑动切换图库中的相邻照片（右滑上一张、左滑下一张），左侧边缘右滑仍保留返回图库手势。
- 编辑配方持久化：每张照片（相册资源按 localIdentifier、文件按尺寸/大小/拍摄时间指纹）自动保存胶片、参数、裁剪、文字与马赛克，重新打开自动恢复，最多延迟 0.7 秒落盘。
- 主页长按多选后新增“批量”菜单：可把最近一次配方一次性套用到所选照片，或按该配方批量导出并写回系统相册（逐张处理、显示进度、可取消）。
- 进阶调色面板：5 点影调曲线、8 段 HSL（红/橙/黄/绿/青/蓝/紫/品红，各含色相/饱和度/明度）与白平衡取样吸管；曲线与 HSL 通过 `CIToneCurve` 与 32³ `CIColorCube` 实现。
- 编辑画布新增前后对比分割线（可拖动）与实况照片播放按钮；实况播放使用 `PHLivePhotoView`，支持重播。
- 导出面板新增胶片边框（无/细边/宽边/拍立得）、日期戳与水印文字，由 `ExportFrameRenderer` 在导出阶段绘制（无边框且无标记时直接返回原图，零额外开销）。
- 主页图库新增格式筛选（全部/RAW/HEIF/PNG/JPEG/TIFF）与时间正倒序切换，格式标签在后台统一计算并缓存。
- 位置权限移入首次启动的权限页，与相机、麦克风、图库并列；相机与设置只会在用户主动开启时才申请授权，使用过程中不再弹出定位弹窗。
- 修复主页缩略图格式徽标不显示（改用后台预计算的标签，避免空视图上的 `.task` 不执行）与编辑页滑动方向相反的问题。
- 实况照片按系统上限固定 12MP（iPhone 17 Pro 在 1× 下同样为 12MP），相机界面在开启实况时明确标注“实况 12MP”，并禁用无效的分辨率切换。

### Build 74

- 主页右上角拼图入口改为白色，与相机、图库按钮统一。
- 相机取景只保留三分构图线，去掉比实际成像范围内缩的白色边线。
- “从文件导入”按钮默认关闭（老版本升级时只迁移一次，之后仍可在设置里手动打开）。
- 胶片浓度上限提升到 200%：`applyFilm` 支持 0…2 的强度，100% 为标准浓度，超过 100% 时在满强度结果上再叠一层胶片底色并微调对比/饱和，150% 与 200% 有明确观感差异；强度数值支持点按快速选择 100/125/150/175/200%。
- 进阶调色从整屏 sheet 改成底部抽屉（约 412pt），上方照片始终可见；抽屉头部带实时预览缩略图，曲线与 HSL 调节可即时看到效果，下拉头部可收起。
- 导出面板内容整体下移、保存按钮固定在底部：左侧“保存到文件”（系统分享/存储到文件），右侧“保存到相册”（默认主操作，直接写入照片图库并显示“已保存到相册”）。
- 导出失败时在面板内直接显示原因（如相册写入权限被拒）。

### Build 75

- 修正导出面板的像素显示：RAW 的第 0 号图像常是内嵌预览（如 1616×1080），改为优先取 EXIF 像素尺寸，必要时用 `CIRAWFilter.nativeSize` 兜底，并按 EXIF 方向换算竖拍尺寸（4000×6000 而不是 6000×4000）；导出时若解码结果明显小于真实像素会直接报错，不再把预览当原图导出。
- 导出面板按内容自适应高度（`GeometryReader` + `PreferenceKey` 量高后设置 detent），去掉“保留相机信息”与两个保存按钮之间的黑色空隙，设置项与按钮紧凑排列。
- 图库格式分类本地缓存：`library-format-labels.json` 存 localIdentifier → RAW/HEIF/PNG…，启动时直接读缓存，只对新增照片后台补算，冷启动即可立即筛选，不再每次重扫全部资源。
- 相机取景按所选比例裁切居中、四周留黑（3:4 / 1:1 / 4:3 / 3:2 / 16:9），做到所见即所得；三分构图线贴合真实取景框。
- 修复前置镜头成片只有 144×192：选择高分辨率格式时排除“照片尺寸大、视频流极小”的格式；采集尺寸异常小或解码结果明显小于源图时直接报错，避免保存马赛克照片。
- 进阶调色抽屉打开时，照片整体上移并等比缩放到剩余可视区域，关闭后恢复原位（`scaleEffect` + `offset` 动画），横拍照片也不会被挡住。
- 前置自拍镜像开关：相机页右上角新增镜像按钮（仅前置时显示），同时切换预览与成片方向，默认开启。

## Sony RAW 兼容性

Sony ARW 的实际解码能力由 iOS/macOS 自带的 Core Image RAW 管线决定，而不是 App 自建解码器。多数主流 Sony 机身已获支持，但非常新的机型、部分压缩 RAW 变体或新固件可能要求更新 iOS。工程会在无法解码时显示明确错误，不会把缩略图冒充全尺寸输出。

正式上架前建议加入一份目标机身清单做回归测试，例如 A7 IV、A7R V、A7C II、A1 II 和 FX3，并使用未压缩、无损压缩及有损压缩 ARW 各测一张。

## 定位与元数据说明

从“文件” App 导入时最容易完整保留 RAW 自身的 EXIF/GPS。通过系统照片选择器导入时，定位是否仍在源文件中取决于 iOS 返回的资产副本与用户授权；RAW+JPEG 资产也可能只返回 JPEG 副本。

关闭地址信息会移除 GPS 主字典，并清理 IPTC 中常见的位置字段；相机、镜头、快门、光圈、ISO 与拍摄时间仍可保留。

## 产出边界
